    %% Pipeline Connections
    VOICE ==> NOISE ==> VAD ==> STT ==> LLM
    CAM ==> OCR ==> LLM
    TOUCH ==> LLM
    TOUCH ==> AYUSH

    LLM ==> SAFETY
    AYUSH ==> REPORT

    SAFETY ==>|Yes: Life Threat| EMERGENCY
    SAFETY ==>|No: Stable Patient| REPORT ==> QUEUE
